This folder contains various scripts and configurations, used by CI or otherwise.

## Checkmk integration contract

Run `.tools/check-checkmk-contract.sh` from the repository root with Docker and
uv available. It builds the repository's Checkmk image, starts a disposable site,
verifies plugin registration, and checks output generated by Watchpost against
the installed plugin and real Checkmk API. The site is removed after the test;
no host ports or persistent named volumes are created.

The smoke test uses the version pinned in
[`Dockerfile.checkmk`](../checkmk-integration/Dockerfile.checkmk), currently
Checkmk Raw 2.4.0p30 on Linux AMD64. ARM64 hosts require Docker's AMD64 emulation.
CI runs this test alongside the regular Python tests on Ubuntu.

To reuse an image you have already rebuilt from the current source, set
`WATCHPOST_CHECKMK_IMAGE` to its tag. Otherwise the script builds it automatically.
The fixture generator runs with Watchpost's Python; the consumer runs with
Checkmk's bundled Python, so the framework need not be installed inside Checkmk.

The fast tests in `tests/test_checkmk_contract.py` use lightweight API doubles;
this Docker test verifies the foreign API and packaging behavior they cannot.
